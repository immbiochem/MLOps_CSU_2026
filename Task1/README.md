# Task1

Скрипт llama.py запускается следующей командой:

*python3 llama.py --model lama --log lama_log.txt*

> --model: доступные модели, у меня это Llama-3.2-3B-Instruct-Q4_K_M и Qwen2.5-3B-Q5_K_M

> --log: текстовый файл, куда запишется лог


(Llama-3.2-3B показывает хорошие результаты, Qwen не показывает)
