# Task5

## RAG-бот (PB.py) с базой данных по последовательностям CDR3 региона антител

> В биоинформатическом анализе репертуара антител могут найтись молекулы, которых очень много у пациента, что свидетельствует о том, что идет иммунный ответ на что-либо

> Боту можно передать аминокислотную последовательность интересующей молекулы (CDR3 региона тяжелой цепи антитела), начиная с символа *

> Бот выведет топ 2 антитела из небольшой кастомной базы данных, а также укажет тип заболевания, при котором это антитело было найдено, что позволит предположит соответствующие изменения у пациента (спрогнозировать его возможное состояние)

Скрипт с ассистентом PeiKibBreat2.py запускается следующей командой:

*python3 PB.py*
