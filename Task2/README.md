> Как рассчитать объем выборки для регрессии Пуассона?
Pei Kib Breat: Для расчёта объёма выборки в регрессии Пуассона (анализ частотных данных) используется формула для двумерной таблицы с двумя группами:

\[
n = \frac{(Z_{\alpha/2} + Z_{\beta})^2 \cdot [p(1-p) + (p_1 - p_0)^2]}{d^2}
\]

где  
- \(p\) — ожидаемая вероятность положительного результата,  
- \(p_1, p_0\) — ожидаемые частоты в группах (или вероятности),  
- \(d\) — ожидаемый эффект (разница \(p_1 - p_0\)),  
- \(Z_{\alpha/2}\) — критическое значение для \(\alpha\) (обычно 1.96 для \(\alpha=0.05\)),  
- \(Z_{\beta}\) — критическое значение для мощности \(1-\beta\) (например, 0.84 при \(\beta=0.2\)).

**Пример**:  
Если \(p=0.5\), \(p_1=0.7\), \(p_0=0.3\), \(\alpha=0.05\), \(\beta=0.2\), \(d=0.4\):  
\[
n = \frac{(1.96+0.84)^2 \cdot [0.5\times0.5 + (0.7-0.3)^2]}{0.4^2} = \frac{7.84 \cdot [0.25 + 0.16]}{0.16} = \frac{7.84 \cdot 0.41}{0.16} \approx 20.2
\]  
Округляем до 21.

Для сложных случаев (много групп, нелинейные зависимости) используют модели на основе максимальной правдоподобия или адаптации метода Крюгера.

Если вам нужен именно для оценки коэффициента регрессии Пуассона (а не для теста связи), объём выборки не расчёзывается — он определяется мощностью и точностью.
